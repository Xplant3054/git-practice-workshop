# Git Workshop Pratice Repo

Your job: add yourself as a contributor through a pull request.

## Steps
1. Click Fork (top right) to copy this repo to your account
2. cd ~/git-workshop, then clone YOUR fork (not this repo)
3. git switch -c add-<your-github-username>
4. Create contributors/<your-github-username>.md with a line about yourself
5. git add . and git commit -m "Add <your-github-username>"
6. git push -u origin add-<your-github-username>
7. On GitHub, click "Compare & pull request" and open the PR
